# 위클리 리뷰

**데일리와 다른 점**: 위클리는 **문서 정비를 겸한다.** 아래 갱신 항목을 빠뜨리면 다음 주 내내 낡은 수치로 브리핑하게 된다.

---

## 1. 절차

```
□ 1. .venv/bin/python tools/snapshot.py --days 10   → 지수 10일 추이
□ 2. .venv/bin/python tools/btc_snapshot.py         → BTC 현황
□ 3. 웹서치 — 지난주 리뷰용 사실 확인 + 다음 주 예상치
□ 4. 지난주 편향 채점 집계 → 적중률·확신도별·(BTC는)근거 층별
□ 5. 아래 2장 '갱신 항목' 전부 처리
□ 6. weekly/YYYY-MM-DD.md 작성
□ 7. .venv/bin/python tools/audit_docs.py → 0건 확인 후 커밋+푸시
```

포맷은 `PLAN.md` 「위클리 리뷰」를 따른다.

---

## 2. ⭐ 갱신 항목 (위클리에서만 하는 일)

### 2-1. 판정 임계값 재산출 — 변동성 국면이 바뀌었는지

```bash
# 60거래일 고저폭 평균을 재계산하고 문서의 임계값과 대조
.venv/bin/python tools/btc_snapshot.py --days 60   # BTC 임계값 재확인
```

- **규칙**: 방향성 임계값 = **60거래일 고저폭 평균의 약 1/5** · 중립 밴드 = **밴드내 비율이 45~50%**가 되는 값 (`lessons.md` 「판정 임계값 산출 규칙」·「중립 밴드 산출 규칙」)
- 현재: **MNQ ±0.3%(중립 ±0.7%) · MES ±0.2%(±0.5%) · BTC ±0.6%(±1.2%)**
- ⚠ **임계값은 위클리에서만 바꾼다.** 데일리에서 스냅샷을 보고 즉석 조정하지 않는다 — 기록의 시간 비교가 깨진다
- ⚠ **20일 창을 쓰지 않는다.** 국면에 끌려 임계값이 흔들린다 (2026-09-20 개정 경위는 `lessons.md`)

### 2-2. `tools/calendar_2026.yaml` 다음 주 항목 재확인

- 특히 **`confirmed: false`** 항목을 웹서치로 확인해 `true`로 올리거나 날짜를 고친다
- ⚠ **1차 출처로 확인한다** — 2026-09-20에 PCE가 9/25로 잘못 들어 있었고, **뉴욕 연준 공식 일정표**(`newyorkfed.org/research/calendars/`)로 9/30임을 확인했다. 실적은 **회사 IR 공식 발표**를 본다(마이크론도 매체의 9/23이 아니라 IR 9/30이었다)

### 2-3. 시장 배경 갱신 — **두 스킬을 각각 고친다**

| 갱신 대상 | 내용 |
|---|---|
| `.claude/skills/briefing-index/SKILL.md` 4장 | 연준·금리·곡선·유가·섹터·일정·COT·롤오버 |
| `.claude/skills/briefing-btc/SKILL.md` 4장 | ETF 자금흐름·펀딩비·OI·스테이블코인·상관표·규제 |
| `CLAUDE.md` 9장 | **핵심 6줄만** — 절대 잊으면 안 되는 것 |

⚠ **세 곳에 같은 숫자를 복사하지 않는다.** `CLAUDE.md`는 **요약만**, 상세는 각 스킬에만 둔다. 중복은 낡은 수치 잔존의 원인이다 (2026-09-20에 21곳에서 발견 — `lessons.md` 패턴 21)

### 2-4. `reviews/lessons.md` 갱신

- **반복 패턴** — 이번 주 오류가 기존 패턴의 재발인지, 새 패턴인지 판단해 추가
- **다음 점검 항목** — 처리된 것은 `[x]`로, 새로 생긴 것은 추가
- ⚠ **번호 체계를 지킨다**: 오류는 `①~⑭`(동그라미, `## 오류 분석` 섹션) / 패턴은 `0~21`(아라비아, `## 반복 패턴` 섹션). **섞어 쓰면 참조가 깨진다** — 2026-09-20에 깨진 참조 10건이 생겼다

### 2-5. 미결 항목 점검

- `PLAN-BTC.md` 10장 「여전히 미결」 — 확신도 '상' 발동 기준 · 온체인 지표 편입 · BTC-나스닥 상관 임계 0.6의 타당성 · 펀딩비 극단 기준의 실전 검증
- ⚠ **"데이터 없음"을 쓰기 전에 후보를 최소 3곳 실제 호출한다** (`lessons.md` 패턴 17 — 이걸 안 해서 두 번 틀렸다)
- ⚠ **새 지표를 채택하기 전에 선행 상관을 측정한다.** 동시 상관만 있으면 **확인용으로 강등**한다 (`lessons.md` 패턴 18)

## 3. 위클리 채점

- 지난 위클리에서 낸 **다음 주 편향**을 그 주 등락으로 채점하고 `reviews/bias-log-<상품>.md`의 「위클리 채점」 표에 추가
- 데일리 채점 집계도 함께 갱신 — **총 횟수·O/△/X·확신도별**, BTC는 **근거 층별**까지
- ⚠ **확신도 '상'은 지수 22회 동안 한 번도 쓰지 않았다.** 어떤 조건에서 쓸지가 아직 미결 항목이다
