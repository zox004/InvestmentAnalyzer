# 비트코인 브리핑 (BTC)

**설계 근거는 `PLAN-BTC.md`.** 이 스킬은 **절차와 현재 BTC 배경**을 담는다.
분석 원칙(사실 vs 가정·추세 우선·유보형 금지·반대 증거 반영 등)은 `CLAUDE.md` 3~7장을 따른다.

## ⚠ 먼저 — 지수 규칙을 가져오지 않는다

| 지수에서 쓰는 것 | BTC에서는 |
|---|---|
| 지표 → 연준 → **금리** → 업종/밸류에이션 → 지수 | **유동성 → 자금흐름 → 레버리지 → 가격** (4층) |
| **상쇄 요인 비교** (`CLAUDE.md` 3-3) | ❌ 업종이 없어 성립 안 함 → **층 정렬 규칙**(`PLAN-BTC.md` 4장) |
| **COT** (1차 근거 금지) | 🔄 **펀딩비** — 시차·헤지 없음, **극단(±0.05%/8h)에서만** 1차 근거 |
| 롤오버 관리 | ❌ 무기한 → **펀딩비가 보유 비용** |
| 정규장 종가 채점 | 🔄 **UTC 일봉 종가** (BTC-나스닥 상관 +0.259로 미국 세션에 묶이지 않음) |

**금리를 BTC 근거로 쓸 때 '할인율'로 풀면 틀린 논리다** — BTC-10년물 설명력 **1%**. **유동성 경로로 풀어야 한다.**

## 2. 편향 결정 — `PLAN-BTC.md` 4장 규칙을 그대로 적용한다

**요약** (전체 표와 27개 조합은 `PLAN-BTC.md` 4장):

1. **1단계** — 1층(유동성·달러)과 2층(자금 흐름)으로 방향을 정한다. 각 층은 **강세/약세/중립** 셋 중 하나
   - 같은 방향 → 그 방향 / 한쪽만 방향 → 그 방향·확신도 **하** / 반대 또는 둘 다 중립 → **중립**
2. **2단계** — 3층(레버리지)으로 **강도만** 조정. 편향과 같은 방향 극단 → 확신도 ↓ / 반대 방향 극단 → ↓↓, '중' 이하면 **중립**
3. **확신도 상한**: 기본 **중**. 2층 미확인 → **중** · 3층만 근거 → **하** · BTC-나스닥 상관 0.6 초과 → **상 금지**
4. **4층 충격** → 방향 내지 않고 **조건부 시나리오**

**⚠ 어휘를 고정한다.** 판정 칸에는 **강세/약세/중립만** 쓴다. *"방향 불분명"·"엇갈림"·"일부만 약세"* 같은 말은 **이유 칸**에 쓴다. 어휘가 흔들리면 규칙 적용을 검증할 수 없다 (2026-09-20 첫 브리핑에서 실제로 세 표현을 섞어 썼다).

**⚠ 3층의 판정 기준은 펀딩비뿐이다.** OI·가격 조합과 롱숏비율은 **서술용 보조**다 — 실측 결과 **p=0.280으로 유의하지 않고 중위값은 동일**했다 (`PLAN-BTC.md` 2-3). **"숏 청산제 상승이니 되돌림이 쉽다"를 편향 근거로 쓰지 않는다.**
